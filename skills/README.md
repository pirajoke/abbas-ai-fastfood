# Навыки (Skills)

**Навык** — это сохранённая инструкция для одной повторяющейся задачи. Вместо того чтобы каждый раз объяснять AI, кто он, что делать и в каком виде вернуть результат, вы один раз записываете это в навык и пользуетесь им снова и снова.

Каждый `SKILL.md` устроен одинаково: назначение → когда использовать → что нужно на входе → порядок работы → формат результата → границы → что проверяет человек → **«Версия для Gemini»** → учебный пример.

---

## Важно про совместимость

- Файл `SKILL.md` — это обычный текст в формате Markdown. Его можно открыть в любом редакторе и прочитать глазами.
- **Веб-приложение и мобильное приложение Gemini не обязаны уметь импортировать `SKILL.md`.** Не рассчитывайте на кнопку «загрузить навык». Основной способ для Gemini — способ 1 или 2 ниже.
- Формат папки с `SKILL.md` (Agent Skills) понимают некоторые инструменты для разработчиков. Поддержка зависит от инструмента и его версии — проверяйте документацию.

## Способ 1. Вручную — работает везде

1. Откройте нужный `SKILL.md` (двойной клик или любой текстовый редактор).
2. Найдите раздел **«Версия для Gemini»** и скопируйте текст из серого блока целиком.
3. Откройте новый чат в Gemini, вставьте текст.
4. Замените всё в `[квадратных скобках]` своими данными или прикрепите файлы кнопкой «+».
5. Отправьте.

Плюс: работает в любой версии Gemini и в других чат-ботах. Минус: каждый раз нужно копировать.

## Способ 2. Gem в Gemini — рекомендуем

**Gem** — это ваш собственный помощник внутри Gemini с постоянной инструкцией и файлами-знаниями. Создавать Gem удобнее на компьютере в веб-версии.

1. Откройте <https://gemini.google.com> и войдите в Google-аккаунт.
2. В боковом меню найдите раздел **Gems** и нажмите «Создать Gem» (названия кнопок могут немного отличаться).
3. **Название:** например, «Сводка смены» или «Аналитик меню».
4. **Инструкции:** вставьте текст из раздела «Версия для Gemini» нужного навыка. Строку `[вставьте …]` можно удалить — данные вы будете давать в каждом чате.
5. **Знания:** добавьте файл `BUSINESS_CONTEXT` (с компьютера или из Google Drive). Для Аналитика меню можно добавить и таблицу меню с себестоимостью.
6. Сохраните. Теперь в начале работы выбирайте этот Gem и сразу пишите задачу: «Вот заметки за сегодня: …».
7. Проверьте Gem на одном реальном примере. Если результат не тот — исправьте инструкцию и сохраните снова.

Советы:
- Один Gem — одна задача. Не смешивайте сводку смены и маркетинг в одном Gem.
- Если вы обновили `BUSINESS_CONTEXT`, обновите файл и в «Знаниях» Gem.
- Ограничения по числу и размеру файлов в «Знаниях» зависят от версии и тарифа — смотрите справку Google.

## Способ 3. Agent Skills — если ваш инструмент это поддерживает

Этот способ для тех, кто уже пользуется инструментами для разработчиков. Абасу на старте он не нужен.

Общий принцип: папка навыка (например, `daily-operations-manager/` с файлом `SKILL.md` внутри) кладётся в каталог навыков инструмента. Инструмент читает `name` и `description` из шапки файла и подключает навык, когда задача подходит.

Примеры (проверьте документацию своей версии — пути и команды меняются):

| Инструмент | Куда положить папку навыка |
|---|---|
| Gemini CLI (в версиях с поддержкой Agent Skills) | `~/.gemini/skills/<навык>/` или `.gemini/skills/<навык>/` в папке проекта; в некоторых версиях есть команда `gemini skills install <путь>` |
| Claude Code | `~/.claude/skills/<навык>/` или `.claude/skills/<навык>/` в проекте |
| Claude (claude.ai) | Настройки → навыки → загрузить ZIP-архив с папкой навыка, если функция доступна в вашем тарифе |

Папку навыка можно взять прямо с GitHub: <https://github.com/pirajoke/abbas-ai-fastfood/tree/gh-pages/skills>. В инструментах, которые умеют ставить навыки из git-репозитория, укажите адрес репозитория `https://github.com/pirajoke/abbas-ai-fastfood` (ветка `gh-pages`, папка `skills/`) — проверьте синтаксис в документации своей версии.

Если инструмент не находит навык — используйте способ 1. Результат будет тем же: текст инструкции один и тот же.

## Как написать свой навык

Когда вы сделали одну и ту же задачу вручную 3–5 раз и результат устраивает:

1. Скопируйте любую папку навыка и переименуйте (латиница, через дефис: `staff-schedule-helper`).
2. В шапке файла поменяйте `name` (как у папки) и `description` (одна фраза: что делает и когда использовать).
3. Заполните разделы своими словами: вход, шаги, формат результата, границы, проверки человеком.
4. В «Версию для Gemini» положите тот промпт, который у вас уже хорошо работает.
5. Проверьте навык на новых данных и поправьте.

Хороший навык: одна задача, понятный вход, фиксированный формат результата, явный список того, что проверяет человек.
