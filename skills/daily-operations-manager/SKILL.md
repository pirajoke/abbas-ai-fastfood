# Daily Operations Manager — сводка смены

> Как подключить навык: вручную, через Gem или как Agent Skill — см. [`skills/README.md`](../README.md).

## Назначение

Владелец за 2 минуты узнаёт, что произошло за смену, что нужно решить и что сделать завтра. Проблемы видны в тот же день, а не через неделю.

## Когда использовать

- Каждый вечер после закрытия (управляющий присылает заметки).
- Утром до открытия (владелец делает сводку из вчерашних заметок).
- В конце недели — сводка по 7 дневным сводкам.

## Что нужно на входе

- Заметки управляющего или расшифровка голосового сообщения (2–3 минуты).
- Итоги кассы: выручка, число чеков (если есть).
- По желанию: вчерашняя сводка — для сравнения.

## Порядок работы

1. Отделить факты от впечатлений («вроде больше, чем вчера» — это впечатление).
2. Разложить по разделам: продажи, закупки и остатки, проблемы, решения на завтра, вопросы владельцу, отзывы и жалобы.
3. В продажах — только цифры из данных. Нет цифр — «нет данных».
4. Закупки — только предлагать; объёмы — «уточнить по остаткам».
5. Решения на завтра — не больше трёх, по одному действию.
6. Последняя строка — «Главное на завтра».

## Формат результата

```text
Сводка смены · [дата]
Продажи: …
Закупки и остатки: …
Проблемы смены: …
Решения на завтра: 1) … 2) … 3) …
Вопросы владельцу: …
Отзывы и жалобы: …
Главное на завтра: …
```

## Границы и безопасность

- Не выдумывать цифры и события.
- Не заказывать, не оплачивать и не отправлять ничего поставщикам.
- Не включать в сводку персональные данные сотрудников (используйте роли: «кассир», «повар»).
- Происшествия, связанные с безопасностью или здоровьем, — отдельной строкой в начале сводки как срочные.

## Что проверяет человек

- Цифры продаж — по отчёту кассы.
- Объёмы закупок — по остаткам на складе.
- Сохранить сводку: `Drive / 04_Операции / Сводки / ГГГГ-ММ-ДД_сводка`.

## Версия для Gemini

```text
Ты — операционный помощник владельца фастфуд-заведения.
Ниже — заметки управляющего после смены [дата] и данные кассы (если есть).
[вставьте заметки или расшифровку голосового сообщения]
[вставьте итоги кассы: выручка, число чеков — если есть]

Задача: сделай сводку смены, которую владелец прочитает за 2 минуты.
Разделы:
1. Продажи — только цифры из данных; если цифр нет, напиши «нет данных».
2. Закупки и остатки — что закончилось, что заказать (объём — «уточнить по остаткам»).
3. Проблемы смены — люди, оборудование, гости.
4. Решения на завтра — не больше 3 пунктов, по одному действию на пункт.
5. Вопросы владельцу — что требует его решения.
6. Отзывы и жалобы за день — если упоминались.

Ограничения: не выдумывай цифры и события. Отделяй факты от предположений («Допущение:»). Закупки и платежи только предлагай — подтверждает человек.
Формат: короткие пункты, без воды. В конце — одна строка «Главное на завтра».
```

Для недельной сводки прикрепите 7 дневных сводок и напишите:

```text
Вот сводки смен за неделю. Сделай итог недели: повторяющиеся проблемы (сколько раз), что улучшилось, что ухудшилось, 3 решения на следующую неделю. Только по данным из сводок.
```

## Учебный пример (заметки вымышленные)

Вход:

```text
закрыли смену. по кассе сегодня [сумма], вроде больше чем вчера. картошка кончилась в 21:00 — убрали фри из комбо. булки привезли в 12, а не в 10. новый кассир путает допы, было два возврата. фритюр №2 шумит, надо мастера. в гугле новый отзыв про долгое ожидание. завтра вечером футбол — людей будет много
```

Ожидаемая сводка: продажи — по отчёту кассы; закупки — увеличить заказ картофеля (объём по остаткам), булки пришли на 2 часа позже; проблемы — кассир путает допы, шумит фритюр №2, отзыв об ожидании; решения — инструктаж по допам до открытия, мастер по фритюру, усилить вечернюю смену; вопросы владельцу — объём картофеля, кто выходит вечером.
