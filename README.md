# AI для фастфуд-бизнеса — воркшоп для Абаса

**От первого промпта до собственного AI-помощника.**

Интерактивный воркшоп на русском языке для владельца фастфуд-заведения, который только начинает работать с нейросетями. Основной инструмент — Google Gemini. Итог дня: первый рабочий AI-процесс на задаче заведения и измеримый показатель успеха.

Методологическая основа — воркшоп «Персональная AI-система» (`personal-ai-system-workshop.ru.html` из `pirajoke/instant-ppt-share`): цикл «контекст → агент → навыки → результат → сохранение». Здесь он переработан под фастфуд и под пользователя без технической подготовки: вместо Obsidian, MCP и Claude Code — Gemini, Gems и Google Drive.

## Как открыть презентацию и инструкцию

1. Распакуйте архив целиком — папка `assets/` должна лежать рядом с `index.html` и `instructions.html`.
2. Дважды щёлкните `index.html` (презентация) или `instructions.html` (инструкция): откроется в Safari или Chrome. Интернет нужен только для перехода по ссылкам на сервисы.
3. Управление:
   - `→`, `пробел`, `PageDown` — вперёд; `←`, `PageUp` — назад;
   - `Home` / `End` — первый и последний слайд;
   - `M` — содержание; `F` — полный экран;
   - на телефоне — свайп влево и вправо;
   - кнопки внизу справа появляются при движении мыши.
4. Ссылка на конкретный слайд: `index.html#slide-12`.
5. На экранах меньше половины 1920×1080 (телефон, узкое окно) слайды автоматически перестраиваются в одну колонку с прокруткой.

## Печать и PDF

- Готовые PDF: `exports/AI-dlya-fastfood-workshop.pdf` (презентация) и `exports/AI-dlya-fastfood-instructions.pdf` (инструкция).
- Свой PDF: откройте `index.html` в **Chrome** → `M` → «Печать / PDF» → «Сохранить как PDF». Размер страницы задаётся автоматически (16:9, один слайд — одна страница). Включите «Фоновые изображения».
- Safari может игнорировать размер страницы из CSS — для PDF используйте Chrome или готовый файл.

## Правила, встроенные в материалы

- Все цифры, меню, отзывы и заметки — **учебные** и помечены как учебные. Данные о бизнесе Абаса не выдумывались.
- **Красная зона:** цены, состав и аллергены, пищевая безопасность, платежи и публикации AI не подтверждает — решает человек.
- Никаких паролей, номеров карт и персональных данных в AI.
- Отметки чек-листа на слайде 17 хранятся только в браузере пользователя (`localStorage`) и никуда не отправляются.

## Что проверено

- 17 слайдов в Chrome при 1920×1080: нет обрезанного текста, выхода за границы и наложений блоков. Проверено автоматически, в том числе после кликов во всех интерактивных состояниях.
- Мобильная вёрстка (390×844) и планшет (768×1024): нет горизонтального переполнения.
- Навигация (клавиатура, кнопки, содержание, хэш-ссылки), копирование промптов в буфер обмена и сохранение чек-листа после перезагрузки проверены автоматически.
- Тексты промптов в презентации дословно совпадают с `PROMPT_LIBRARY.md` и навыками.
- Инструкция: 17 слайдов без переполнения при 1920×1080 и 390×844; окно навыка, копирование промптов и навыков, отметки шагов, переходы по карте маршрута проверены автоматически; все внешние ссылки открываются (проверены запросом).
- PDF: каждая страница просмотрена визуально.
- Safari: вёрстка написана с учётом Safari (префиксы `-webkit-`, без экспериментальных функций), но автоматически в Safari не тестировалась. Перед показом стоит открыть презентацию в Safari один раз.
